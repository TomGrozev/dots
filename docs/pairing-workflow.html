Only other stop: the hard stop — if implementation needs a new persisted data shape or cross-module contract the skeleton doesn't have, the AI stops, you decide, and the decision becomes an ADR.

Terms

TermMeaning
hitl / afkTicket mode: who is in charge. hitl (human in the loop, label ready-for-human) = the ticket changes the public surface, or has a puzzle you take. afk (away from keyboard, label ready-for-agent) = everything else, incl. anything describable in one sentence. Same words wayfinder uses for its tickets.
Public surfaceModules and where they live, public function heads + types, schemas/migrations, contracts between modules. Yours.
SkeletonThe public surface as real code in the real files, bodies not implemented. You edit it in your editor and say "go".
PuzzleA piece of a ticket's internals where the thinking is the work: an algorithm, state machine, edge-case policy, ordering/concurrency, a non-obvious query. Usually 0–3 per ticket, often none. Everything else is a chore (wiring, boilerplate, tests, CSS) and is never offered.
Ping-pongAI writes the failing tests + a TODO(human) stub with context and tradeoffs. You write the code; AI reviews it like a pair.
Strong-styleYou navigate, AI drives: AI offers 2–3 approaches, you pick or sketch, AI types it.
SoloAI does it alone; you see it in the walkthrough.
TestsDerived by the AI from the spec's user stories/testing decisions and the ticket's acceptance criteria. You never write or approve a test list.
GateOne command in the repo's agent file under ## Gate (written by onboard), e.g. tests + compiler + linter + formatter. It is one repo-owned command — the repo's pre-commit hook runs the same one — and must pass with output shown before the review.
Blind reviewA reviewer that sees only skeleton, acceptance criteria and diff — not the implementer's reasoning — looking for untested criteria, duplicated code, and changed semantics behind a stable interface.
Stack packrule://stack-<name>, e.g. stack-elixir: language-wide rules that auto-load when the AI edits that language's files.
